# DevOps Engineering Playbook

## Delivery
CODE → REVIEW → CI → QUALITY → SECURITY → IMAGE → REGISTRY → DEPLOY → VERIFY

## Incident Response
DETECT → INVESTIGATE → ROOT CAUSE → FIX → TEST → RECOVER → PREVENT

## Kubernetes
CHECK PODS → EVENTS → LOGS → DESCRIBE → SERVICE → ENDPOINTS → PROBES → RESOURCES

## Infrastructure
Terraform → fmt → validate → plan → review → apply → verify → drift check

## Reliability
Measure SLI → define SLO → protect error budget → reduce MTTR → improve continuously

## Engineering Principles
- Prefer automation over repetitive manual work.
- Treat infrastructure as code.
- Keep public exposure minimal.
- Design for observable failure.
- Make rollback and recovery part of delivery.
